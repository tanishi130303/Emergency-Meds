# 急変時 初期投与メニュー

救急・病棟急変時に「計算せず・反射的に」指示出しできるためのクイックリファレンス（体重50kg想定）。
検索・カテゴリ絞り込み・ダーク基調・PWA（オフライン／ホーム画面追加）対応。

## 項目の増やし方

`index.html` の冒頭にある `DATA` 配列を編集するだけ。1ブロック＝1つの「状況」で、中に薬剤を並べる。

```js
{
  category:"循環器",              // 循環器/ショック/呼吸器/神経/代謝内分泌/消化器 の6系統
  scenario:"〇〇の初期対応",      // 具体名はここに（カテゴリは大きく束ねる方針）
  goal:"治療目標（任意）",
  point:"使い分け・ポイント",     // 任意。青いボックスで目標の下に表示。\n で改行可
  drugs:[
    {
      name:"薬剤名",              // 必須。手順型なら "① 〇〇" のように番号を振ってもよい
      brand:"商品名",             // 任意
      tag:"ラベル",               // 任意。配列も可 ["β遮断","EF低下"]
      prep:"希釈・準備",
      start:"初期投与",            // ★緑で強調される最重要欄
      titrate:"調整・漸増",         // 任意
      note:"適応・補足",           // 任意（\n で改行可）
      warn:"⚠️注意",              // 任意（赤）
      tip:"💡コツ"                // 任意（黄）
    }
  ]
}
```

カテゴリは臓器系統の6グループに固定。項目が増えても基本はこの6つのどれかに割り振るだけで、
チップは増えません（具体名は scenario タイトルで表示）。
どうしても新グループが必要なときは、`CATS` 配列・`:root` の `--c-グループ名`・
`.chip` / `.scn` / `.catbadge` の各CSSルールにそれぞれ1行ずつ追加する。

## GitHub Pages へのデプロイ

1. 新規リポジトリを作成（例: `kyukyu-menu`）
2. `index.html` / `manifest.json` / `sw.js` / `icon.svg` をそのまま push
3. Settings → Pages → Branch: `main` / フォルダ: `/ (root)` で公開
4. 表示された URL をスマホで開き、ブラウザの「ホーム画面に追加」でアプリ化

データを更新したら `index.html` を push し直すだけ。オフライン時も最後に開いた内容が表示される。

## 注意

希釈方法・投与速度は施設プロトコル（プレフィルド製剤の有無等）で異なる。
投与前に必ず各自で確認すること。記載は体重50kg想定の目安。
